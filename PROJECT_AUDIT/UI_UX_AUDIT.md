الواجهة متناسقة وسلسة، RTL-first صحيح، وتجربة الطفل بسيطة. أبرز الضعف: غياب الصور والرسومات الحقيقية، لا شخصية كارتونية، وتجربة المكتبة المفتوحة تحتاج تطوير.

## 1. تحليل الصفحات والشاشات

### صفحة الاستقبال (Landing)
**الملف:** `apps/web/src/app/(marketing)/page.tsx`

✅ **ما يعمل:**
- Hero section واضح مع CTA "ابدأ الآن"
- عرض 7 عوالم بألوان متدرجة
- قائمة 6 ميزات موجزة
- لا إعلانات / لا بطاقة بنكية — محدد صراحة

⚠️ **ما يحتاج تحسين:**
- لا توجد صور أو مقاطع فيديو حقيقية — كل شيء إيموجي ونصوص
- لا testimonials أو أرقام حقيقية (عدد المستخدمين، القصص)
- CTA الثانوي "استكشف العوالم" يُعيد للصفحة نفسها (anchor `/#worlds`) — يعمل

### صفحة تسجيل الدخول / التسجيل
**الملف:** `apps/web/src/app/(auth)/auth/login/page.tsx`

✅ **ما يعمل:**
- تصميم بطاقة مركزية بظل محسوس
- رسائل خطأ باللغة العربية
- Suspense boundary حول `useSearchParams`
- رابط "نسيت كلمة السر"

⚠️ **ما يحتاج تحسين:**
- لا social login (Google) — قد يرفع معدل التسجيل
- لا password strength indicator

### لوحة تحكم الطفل (KidDashboard)
**الملف:** `apps/web/src/app/(child)/kids/[childId]/KidDashboard.tsx`

✅ **ما يعمل:**
- أصوات بسيطة عند الإنجاز (Web Audio API)
- تحدي أسبوعي واضح
- آخر نشاط + شارات حديثة
- عرض عوالم بشريط تقدم

⚠️ **ما يحتاج تحسين:**
- لا شخصية كارتونية (mascot) ترحب بالطفل — غياب واضح مقارنة بعصافير
- الألوان متناسقة لكن لا توجد حيوية بصرية (animations عند الدخول)

### صفحة القصص
**الملف:** `apps/web/src/app/(child)/stories/page.tsx`

✅ **ما يعمل:**
- تقسيم "قصص بصوت + تمارين" vs "قصص للقراءة"
- فلترة بالمستوى
- اظهار ✓ على القصص المقروءة
- loading skeleton موجود (`loading.tsx`)

⚠️ **ما يحتاج تحسين:**
- أغلفة القصص إيموجي فقط — لا صور حقيقية
- عدم وضوح ماذا سيجد الطفل داخل القصة (ملخص مختصر جداً)

### قارئ القصص (StoryReader)
**الملف:** `apps/web/src/app/(child)/stories/[slug]/StoryReader.tsx`

✅ **ما يعمل:**
- مشاهد متحركة (SVG/emoji) جميلة
- تلوين الكلمة المقروءة أثناء TTS
- قراءة تلقائية بالصفحات (auto-advance)
- تبويب المفردات والتمارين
- شريط تقدم واضح

⚠️ **ما يحتاج تحسين:**
- الأصوات TTS متدنية الجودة (حتى يُشغَّل script توليد MP3)
- لا صور حقيقية للمشاهد — مشاهد emoji جيدة كحل بديل لكن ليست بمستوى عصافير

### المكتبة المفتوحة
**الملف:** `apps/web/src/app/(child)/library/[slug]/LibraryReader.tsx`

✅ **ما يعمل:**
- 532 قصة عربية مرخّصة
- دعم تشغيل الصوت (للقصص التي لديها audio_url)
- auto-advance بين الصفحات
- أزرار تحكم واضحة

⚠️ **ما يحتاج تحسين:**
- صور الكتب من Google Storage — قد تكون بطيئة أو لا تعمل أحياناً
- لا تعمل الكتابة اليدوية (cleanPageText يزيل بعض المحتوى الذي يحتوي JS)

## 3. مقارنة مع عصافير (3asafeer.com)

### ما عند عصافير وليس عندنا

| ميزة عصافير | الوضع في سَلِيم | الأولوية |
|------------|---------------|---------|
| رسومات احترافية ملونة لكل قصة | إيموجي فقط | 🔴 عالية جداً |
| شخصية كارتونية مميزة (mascot) | غير موجودة | 🔴 عالية |
| مكتبة بمئات الكتب المصنّفة بالمستوى والسن | 532 قصة ✅ | متعادلان |
| نظام اشتراك (Free/Premium) | مجاني كلياً حالياً | ستُضاف لاحقاً |
| قراءة صوتية بأصوات احترافية | TTS متدني (MP3 قريباً) | 🟡 متوسطة |
| تتبع قراءة الطفل | ✅ موجود | متعادلان |
| تطبيق iOS محلي | WebView فقط | 🟡 متوسطة |
| تعليق الوالد على النشاط | غير موجود | 🟢 منخفضة |

### ما عندنا وليس عند عصافير (أو ضعيف عنده)

| ميزة سَلِيم | الميزة التنافسية |
|------------|---------------|
| ألعاب تعليمية (6 ألعاب) | عصافير يركز على القراءة فقط |
| دروس بأسئلة فهم + تقييم | نظام تعلم متكامل |
| لوحة رسم + تلوين | إبداع يدوي |
| نقاط وشارات وتحدي أسبوعي | gamification أشمل |
| تسجيل صوت الطفل أثناء القراءة | ميزة فريدة |
| لوحة والدين شاملة | متابعة أعمق |
| إسناد مهام للطفل من الوالد | تحكم أفضل |
| مجاني بالكامل (حالياً) | ميزة تنافسية كبيرة في السوق العربي |

### كيف نتميز ونتفوق على عصافير؟

1. **النظام التعليمي الكامل**: عصافير = قراءة. سَلِيم = قراءة + دراسة + ألعاب + رسم + متابعة
2. **تخصيص المستوى**: تقسيم دقيق بمستويات 1–4 ومرحلة عمرية 3–5 / 6–8 / 9–12
3. **المجانية المبدئية**: بداية مجانية كاملة تبني قاعدة مستخدمين قبل الاشتراك
4. **تسجيل صوت الطفل**: ميزة تعليمية فريدة لتقييم النطق
5. **شراكة مدرسية (Phase 7)**: لوحة معلمين غائبة عن عصافير

## التوصيات الفورية (UI/UX)

1. **أضف صورة واحدة حقيقية على الأقل لكل قصة** — حتى تُنتج بـ AI مفتوح المصدر
2. **صمِّم شخصية كارتونية بسيطة** (mascot) ترحب بالطفل في dashboard
3. **اختبر على هاتف أندرويد حقيقي** قبل أي إطلاق
4. **حسِّن أغلفة القصص** في صفحة المكتبة (emoji ممتعة لكن تحتاج لون خلفية مميز لكل قصة)
5. **أضف loading state** في أزرار الألعاب بعد الضغط
