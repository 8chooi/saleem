### KI-001: ملف `/auth/callback` مكرّر
**التصنيف:** مؤكدة  
**الملفات:**

**الحل:** تحديد أيهما يستخدمه Supabase ثم حذف الآخر.  
**المصدر:** `TASKS.md` (pending)

### KI-004: قصة "الثعلب الذكي" — محتوى مثير للجدل
**التصنيف:** ملاحظة (من `TASKS.md`)  
**الوصف:** مذكور في `TASKS.md` أن قصة "الثعلب الذكي" تحتوي محتوى غير مناسب أو مثيراً للجدل.  
**الأثر:** قد يُحدث ردود فعل سلبية من الوالدين عند الإطلاق.  
**الحل:** مراجعة القصة وتعديلها أو إزالتها من المحتوى النشط.  
**ملاحظة:** لم نقرأ نص القصة مباشرة — قد تكون أُصلحت بالفعل.

## 🟡 متوسطة — تؤثر على أجزاء محددة

### KI-007: تسجيل الصوت (MediaRecorder) غير مختبر على iOS Safari
**التصنيف:** محتملة  
**الملف:** `apps/web/src/components/stories/ReadAloudRecorder.tsx`  
**الأثر:** iOS Safari لا يدعم `webm` format — يحتاج fallback لـ `mp4/m4a`.

---

### KI-008: type casting بـ `unknown` في admin
**التصنيف:** مؤكدة  
**الملف:** `apps/web/src/app/admin/page.tsx` السطر 43–44  
```tsx
const subject = l.subject as unknown as { name_ar: string; emoji: string } | null
```
**الأثر:** TypeScript لا يحمي هذا الكود — أي تغيير في DB schema قد يكسره دون تحذير.  
**الحل:** توليد types تلقائياً: `supabase gen types typescript`

---

### KI-009: أسلوب تحميل الخطوط غير مؤكد
**التصنيف:** محتملة  
**الوصف:** إذا Cairo مُحمَّل بـ `<link>` بدلاً من `next/font` → طلبات خارجية لـ Google Fonts عند كل page load.  
**لم يُتحقق** من الكود الفعلي.

---

### KI-010: `cleanPageText` في LibraryReader قد يحذف محتوى صحيح
**التصنيف:** ملاحظة  
**الملف:** `apps/web/src/app/(child)/library/[slug]/LibraryReader.tsx`  
**الوصف:** الدالة مصممة لإزالة JS code من StoryWeaver — لكن قد تحذف نصاً عربياً إذا احتوى أنماطاً مشابهة.
