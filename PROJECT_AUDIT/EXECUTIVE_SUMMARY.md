## ما هو المشروع؟

سَلِيم منصة تعليمية تفاعلية للأطفال من 3 إلى 12 سنة، تقدّم قصصاً مشكّلة بمستويات مع صوت وتمارين، دروساً قصيرة بأسئلة فهم، ألعاباً تعليمية، لوحة رسم، ومكتبة مفتوحة (532 قصة عربية مرخّصة). الهدف: منافسة منصات مثل عصافير (3asafeer.com) بمنتج أشمل ومجاني يناسب السوق العربي.

## أبرز نقاط القوة

1. **معمارية صلبة**: Monorepo + Next.js 14 App Router + TypeScript strict + Supabase RLS
2. **RTL-first حقيقي**: كل الواجهات مكتوبة بـ `dir="rtl"` من الأساس
3. **نظام محتوى قابل للتوسع**: قاعدة بيانات منظّمة بـ 21 migration يمكن توسيعها دون إعادة بناء
4. **مجاني بالكامل**: صفر تكلفة على كل الخدمات (Supabase Free + Vercel Hobby)
5. **مكتبة فريدة**: 532 قصة عربية مرخّصة جاهزة للقراءة

## أبرز المخاطر والمشكلات

| الخطورة | المشكلة |
|---------|---------|
| 🔴 عالية | Vercel Hobby لا يسمح بالاستخدام التجاري — يجب النقل قبل أي دفع |
| 🔴 عالية | لم يُختبر التطبيق على هاتف حقيقي |
| 🔴 عالية | قصة "الثعلب الذكي" تحتوي رسالة أخلاقية مشكوك فيها — قرار معلّق |
| 🟡 متوسطة | N+1 query في لوحة الوالد (loop per child) |
| 🟡 متوسطة | ملف `/auth/callback` مكرّر في مكانين |
| 🟡 متوسطة | الصوت يعتمد على جهاز المستخدم (TTS) — جودة متفاوتة |
| 🟡 متوسطة | لا توجد صور حقيقية للقصص (إيموجي فقط) |
| 🟢 منخفضة | لا توجد اختبارات تلقائية (unit/integration tests) |
| 🟢 منخفضة | إعدادات SEO أساسية فقط |

6. **أضف rate limiting** على نماذج المصادقة
