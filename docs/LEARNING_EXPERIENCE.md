## مبادئ تجربة التعلم

1. **التدرج** — من السهل للصعب دائماً
2. **التعزيز الإيجابي** — نجاح صغير → تشجيع فوري
3. **السياق** — كل نشاط مرتبط بمهارة واضحة
4. **التنوع** — لا تكرار مزعج للمحتوى
5. **الاستمرارية** — حفظ التقدم دائماً
6. **الوضوح** — الطفل يعرف أين هو وما التالي

---

## هيكل المحتوى التعليمي

```
العالم (World)
└── الوحدة (Unit) — موضوع محدد
    └── الدرس (Lesson) — مهارة واحدة
        ├── محتوى الدرس (فيديو/نص/تفاعل)
        ├── تمرين بسيط
        ├── أسئلة قصيرة (3-5)
        └── نشاط اختياري
```

## نظام النقاط والإنجازات

### النقاط
| الحدث | النقاط |
|-------|--------|
| إكمال درس | 10 نقاط |
| اجتياز اختبار (> 70%) | 15 نقاط |
| اجتياز اختبار (100%) | 25 نقاط |
| قراءة قصة كاملة | 8 نقاط |
| لعبة مكتملة | 5 نقاط |
| تحدي يومي | 20 نقاط |

### الشارات (Phase 5 — أمثلة)
- 🌟 "أول خطوة" — أول درس مكتمل
- 📚 "قارئ نشيط" — 10 قصص مكتملة
- 🏆 "متفوق" — 5 اختبارات بـ 100%
- 🌙 "أمير الحروف" — إكمال عالم الحروف

### القواعد
- لا نقاط وهمية كأنها اكتُسبت
- لا يرى الطفل نقاط طفل آخر إلا في سياق تحديات آمنة
- ولي الأمر يرى نقاط طفله فقط

## نظام Learning Path (قائم على قواعد)

```python
# المنطق المبسط (تُنفَّذ على الخادم)

def get_next_recommendation(child_id, world_id):
    progress = get_child_progress(child_id, world_id)
    
    # لم يبدأ أي شيء؟
    if not progress:
        return get_first_lesson(world_id)
    
    # آخر درس لم يكتمل؟
    if progress.last_lesson.status == 'in_progress':
        return progress.last_lesson
    
    # اجتاز الاختبار بأقل من 70%؟
    if progress.last_quiz_score < 70:
        return get_practice_activity(progress.weak_skills)
    
    # اكتمل الدرس؟
    return get_next_lesson(world_id, progress.completed_lessons)
```

## أنواع المحتوى

### القصص
| النوع | الوصف | العمر |
|-------|-------|-------|
| مصورة | صور + نص | 3-8 |
| صوتية | نص + تعليق صوتي | 3-12 |
| تفاعلية | قرارات تغير المسار | 6-12 |

### الدروس
| النوع | الوصف |
|-------|-------|
| فيديو | مقاطع قصيرة < 5 دقائق |
| نص تفاعلي | نص + صور + تمارين |
| ألعاب تعليمية | مهارة واحدة، قواعد بسيطة |

### الألعاب (Phase 5 — البداية بـ 3)
1. **مطابقة الصور** — صلة مهارة بمهارة، كل الأعمار
2. **ترتيب الحروف/الأرقام** — تسلسل، 3-8 سنوات
3. **الاختيار الصحيح** — أسئلة بصرية، كل الأعمار

## تجربة الاختبار

```
الاختبار القصير (3-5 أسئلة):
- سؤال واحد في الشاشة
- خيارات بصرية + نص
- تغذية راجعة فورية بعد كل سؤال
- لا عقوبة على الخطأ — شجّع إعادة المحاولة
- في النهاية: النتيجة + الشارة (إن وُجدت)
```

## الأداء وتجربة الإنترنت الضعيف

- Lazy loading للصور
- Responsive images (WebP + fallback)
- لا تحميل محتوى مسبق بكميات كبيرة
- محتوى نصي يظهر قبل الصور
- Skeleton loading بدلاً من شاشة بيضاء
- رسالة واضحة عند انقطاع الإنترنت
- PWA offline للمحتوى المحمّل مسبقاً
