## مبادئ المحتوى

1. **أصيل أو مرخص** — لا محتوى مسروق أو مشابه
2. **مناسب للعمر** — مراجعة بشرية إلزامية
3. **عربية سليمة** — فصحى ميسّرة، لا أخطاء لغوية
4. **هدف تعليمي واضح** — كل محتوى مرتبط بمهارة
5. **مراجعة بشرية أولاً** — لا نشر بدون اعتماد

---

## سير عمل اعتماد المحتوى

```
مؤلف/مصمم
    ↓ ينشئ مسودة
نظام المراجعة (CMS)
    ↓ يرفع للمراجعة
مراجع المحتوى
    ↓ يوافق / يطلب تعديل
مشرف المحتوى
    ↓ يعتمد وينشر
المنصة ← المحتوى ظاهر للمستخدمين
```

**قاعدة صارمة:** لا محتوى يصل للأطفال بدون مرور بهذا السير.

## المحتوى الأولي (Seed Content)

للبدء بمحتوى حقيقي من اليوم الأول:

### الحد الأدنى للإطلاق
| النوع | الكمية المطلوبة |
|-------|----------------|
| قصص مصورة (3-5) | 5 قصص |
| قصص مصورة (6-8) | 5 قصص |
| قصص مصورة (9-12) | 3 قصص |
| دروس (عربية) | 10 دروس |
| دروس (رياضيات) | 10 دروس |
| ألعاب | 3 ألعاب |
| اختبارات | 5 اختبارات |

### مصادر محتوى مجانية ومرخصة
- **قصص التراث العربي** — ملك عام (public domain)
- **قصص أصلية** — ينتجها الفريق
- **Creative Commons** — محتوى مرخص بوضوح
- **لا Wikipedia أو مصادر غير مرخصة للمحتوى الصوتي والبصري**

## الذكاء الاصطناعي في المحتوى

### ما هو مسموح
- توليد مسودات (قصص، أسئلة، أفكار)
- مساعدة المؤلف في الكتابة
- اقتراح أفكار أنشطة

### ما هو ممنوع
- نشر محتوى AI بدون مراجعة بشرية
- الاعتماد على AI API مدفوع لتشغيل المنصة
- chatbot يتواصل مع أطفال بدون ضوابط

### الحل الحالي (Phase 0)
محتوى بشري 100% — لا AI في المحتوى المنشور حتى يوجد فريق مراجعة.

## معايير جودة المحتوى

### اللغة
- [ ] لا أخطاء إملائية أو نحوية
- [ ] مستوى اللغة مناسب للعمر
- [ ] العربية الفصحى الميسّرة (ليست عامية، ليست صعبة)
- [ ] الإنجليزية سليمة (للمحتوى الإنجليزي)

### التربوي
- [ ] هدف تعليمي واضح ومحدد
- [ ] التدرج في الصعوبة
- [ ] لا معلومات خاطئة
- [ ] مناسب للقيم والثقافة العربية

### البصري (القصص)
- [ ] رسومات أصلية أو مرخصة
- [ ] جودة بصرية عالية
- [ ] لا محتوى مخيف أو عنيف
- [ ] ألوان مناسبة للعمر
