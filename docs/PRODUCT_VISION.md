## الرؤية الكبيرة

**SALEEM ليس مكتبة قصص.**
**SALEEM عالم تعليمي متكامل (Learning Universe).**

عالم يجمع:
- القراءة + الاستماع + المشاهدة
- اللعب + التفكير + التجربة
- حل المشكلات + الإبداع
- التقييم + التقدم الشخصي

يشعر الطفل أنه يدخل عالماً خاصاً به، وكل نشاط يقوده لاكتشاف جديد.

## Learning Path System — نظام مسار التعلم

### المبدأ
النظام يعرف:
- ما أنجزه الطفل
- المهارات التي أتقنها
- المهارات التي تحتاج تدريباً
- المحتوى المناسب للمرحلة التالية

### التنفيذ (بدون AI مدفوع)
```
قاعدة بسيطة:
1. الطفل يكمل درساً → يُسجّل إتمامه
2. النتيجة > 70% → يُفتح الدرس التالي
3. النتيجة < 70% → يُقترح تمرين مساعد
4. 3 دروس في وحدة → تُفتح وحدة جديدة
5. وحدة كاملة → شارة + اقتراح عالم آخر
```

### ما لا ندّعيه
- لا نقول "النظام يتكيف ذكياً" إلا إذا كان هناك منطق حقيقي
- لا نعرض توصيات وهمية كأنها مخصصة

## تجربة الطفل حسب العمر

### 3-5 سنوات — عالم الاستكشاف
```
الواجهة:
- صور كبيرة جداً
- أزرار واسعة (min 60px)
- لا نص طويل — صور + صوت
- ألوان زاهية مريحة
- شخصية مرشدة (Saleem)

المحتوى:
- قصص مصورة بسيطة
- تعلم الحروف بالأصوات
- الأرقام 1-10
- الألوان والأشكال
- الحيوانات والطبيعة

التفاعل:
- لمس وسحب وتصنيف
- ألعاب المطابقة
- أسئلة بالصور فقط
- تغذية راجعة صوتية فورية
```

### 6-8 سنوات — عالم التعلم
```
الواجهة:
- توازن بين النص والصورة
- أزرار أكبر من العادي (min 48px)
- قوائم بسيطة
- ألوان مبهجة

المحتوى:
- القراءة المتدرجة
- الحساب الأساسي
- اللغة العربية والإنجليزية
- علوم بسيطة
- قصص تفاعلية

التفاعل:
- أسئلة اختيار من متعدد
- تمارين الكتابة (اختيارية)
- ألعاب التفكير
- تحديات قصيرة 3-5 دقائق
```

### 9-12 سنة — عالم التحدي
```
الواجهة:
- واجهة أكثر نضجاً
- أزرار عادية الحجم
- معلومات أكثر في الشاشة
- تصميم عصري نظيف

المحتوى:
- قصص أطول وأكثر تعقيداً
- رياضيات متقدمة
- علوم + تجارب
- تفكير منطقي وألغاز
- مشاريع إبداعية

التفاعل:
- اختبارات متعددة الأسئلة
- تحديات متعددة الخطوات
- مقارنة النتائج (بشكل آمن)
- مسارات اختيارية
```

## الهوية البصرية

### الشعور العام
- **Premium** — ليس قالباً جاهزاً
- **Friendly** — مرحب ودافئ
- **Clean** — مساحات بيضاء كافية
- **Immersive** — يشعر الطفل بعالم حقيقي
- **Elegant** — ليس مبهرجاً

### الشخصيات الأصلية
- شخصية سَلِيم الرئيسية (مرشد) — تُصمَّم أصلياً
- شخصيات مساعدة لكل عالم
- **لا تقليد لشخصيات عصافير أو أي منافس**

### الألوان
- متغيرة حسب العالم
- هادئة ومريحة عموماً
- مبهجة في تجربة الطفل
- Design Tokens قابلة للتعديل
