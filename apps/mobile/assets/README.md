# أصول التطبيق المطلوبة

ضع الملفات التالية في هذا المجلد قبل البناء:

## الملفات المطلوبة

| الملف | الأبعاد | الوصف |
|-------|---------|-------|
| `icon.png` | 1024×1024 px | أيقونة التطبيق الرئيسية — خلفية زرقاء `#2563EB`، شعار سَلِيم أبيض |
| `adaptive-icon.png` | 1024×1024 px | نفس الأيقونة بدون خلفية (foreground layer) |
| `splash.png` | 1242×2436 px | شاشة البداية — خلفية زرقاء، شعار وسط |
| `favicon.png` | 48×48 px | للـ web (اختياري) |

## ملاحظات التصميم

- لون الخلفية الرئيسي: `#2563EB` (أزرق سَلِيم)
- النص الأبيض: `#FFFFFF`
- الخط: Cairo Bold (عربي)
- لا تضع نص أو تفاصيل قرب حواف `icon.png` — Android يقطّع دوائر

## أدوات مقترحة (مجانية)

- **Canva**: قوالب App Icon جاهزة
- **Figma**: تصميم احترافي مجاني
- **Android Asset Studio**: [مباشر](https://romannurik.github.io/AndroidAssetStudio/icons-launcher.html)

## ملف placeholder مؤقت

لتشغيل `eas build` بدون الصور الحقيقية، أنشئ صور بسيطة بأي أداة
أو استخدم expo-asset لتحميلها لاحقاً.
